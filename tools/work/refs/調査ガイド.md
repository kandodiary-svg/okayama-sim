# 岡山・桃太郎大通り 建物外観写真資料集

調査基準日：2026年10月22日

## 何を収集したか

- Wikimedia Commonsの「Momotaro-odori」に掲載された37点と、岡山駅東口の追加6点、合計**43点の写真ファイル**。原寸JPEGを保存し、`photo_credits.csv`に著作者・原典・ライセンスなどを記録した。
- 駅前〜西川緑道公園の両側の主要建物について、名称・住所・個別の外観写真ページを照合した。
- 一般の写真サイト・ホテル公式サイト・岡山市の工事記録などは、複製を避けてリンク集として収録した。

**重要：43点は「43棟を網羅した写真」という意味ではない。** 同じ建物の複数アングル、路面電車、彫刻、歩道、2010年代の写真、城下側までの参考写真を含む。各棟の最新の正面写真と1階の近接写真は、まだ十分にそろっていない。

## 写真の著作権・利用条件

- 収録写真はWikimedia Commonsの各ファイルページでCC BY / CC BY-SA / パブリックドメインと案内されるもの。**著作者・ライセンス・原典URLは必ず`photo_credits.csv`とともに管理**すること。CC BY-SAの写真を加工して共有する場合には同一条件の継承などが必要となる。
- Googleストリートビューは建物の場所を確認するための**閲覧リンク**としては使えるが、Googleの公式ガイドラインは画像のスクリーンショット保存、画像の抽出・ダウンロード、そこからのデータ作成を禁止している。3D用テクスチャの原画として取り込まないこと。参照：https://about.google/brand-resource-center/products-and-services/geo-guidelines/
- その他のニュースサイト、ビル紹介サイト、ホテルサイトの画像は権利を確認できていないため、この資料集には画像本体を収録していない。
- 公開用3Dデータやゲームのテクスチャに転用するときは、建物や看板の写り込みを含め、各ファイルのライセンスと用途を再確認すること。

## 次に不足しているもの

1. 第1区間の**全棟の連続した建物ID付け**（小型店を含む）は未完成。現地で撮影したような「1棟ずつの正対写真」には達していない。
2. 現行の1階の近接写真（店舗入口、看板、ショーウィンドウ）は多くの建物で未取得。
3. 2010年代写真の看板や新旧建物を2026年の状態に置き換える作業が残る。
4. 岡山駅前広場は2026〜2029年に形が変わるため、「2026年現況」と「完成後予想」を別バージョンとして設計した方がよい。

結論：現時点では**形状・規模・街並みの骨格をつくる資料集**として使える。窓割りや1階看板まで正確に再現するには、各ビルの現況写真を追加する必要がある。
