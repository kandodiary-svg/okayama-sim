# 岡山シミュレーター（OKADEN 運転席）

岡山市の中心部とその周り（東西 約11.4km × 南北 約9.1km、約104km²。北は津高台・宿〔岡山大学の北〕、南は泉田・洲崎、西は北長瀬・西長瀬、東は百間川を越えて米田・中川町まで）を 3D で再現したブラウザのシミュレーターです。
中心部（岡山駅〜表町〜岡山城の周り）は建物の外壁写真と車道・歩道の詳しいデータ（PLATEAU）があり、その外の建物は箱形（高さは実測・外壁は推定）です。
路面電車（東山線・清輝橋線）・両備バス 西大寺線・車・ヘリコプター・JR（山陽新幹線は福山〜相生）で街を動けます。車は山陽自動車道（県内の約 100km）も走れます。歩行者・自転車・周りの車・JR の列車も走ります。

- 動かし方: `index.html` をブラウザで開く（同じ場所に `data/`・`audio/`・`sfx/` が必要）。GitHub Pages / Cloudflare Pages でそのまま公開できます
- 基準時点・出典・推定している所の一覧は、画面のメニューの「このシミュレーターの基準時点・出典・推定している所」
